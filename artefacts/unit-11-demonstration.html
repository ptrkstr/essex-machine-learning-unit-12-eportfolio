Demonstration: Screening a Chest Radiograph with Both Models¶

Machine Learning (PCOM7E), Unit 11 Individual Presentation. Data: the paediatric radiograph release of Kermany, Zhang and Goldbaum (2018) on Mendeley Data. Library versions match those printed at the top of the main notebook, since the saved models can only be reloaded by compatible versions.

This notebook loads the two models trained and saved by pneumonia-classical-vs-deep-learning.ipynb and screens individual radiographs from the held-out test set. It runs in a few seconds without retraining anything, and is shown in the presentation as a recorded screen capture.

Dependencies¶

This notebook requires tensorflow, scikit-learn, scikit-image, opencv-python, numpy, matplotlib and joblib. It also needs two things produced or downloaded for the main notebook: the models/ folder written by the final cell of pneumonia-classical-vs-deep-learning.ipynb (placed next to this notebook), and the chest X-ray test images of Kermany, Zhang and Goldbaum (2018), unzipped from ChestXRay2017.zip into a chest_xray folder next to this notebook, or anywhere else named by the CHEST_XRAY_DIR environment variable.

The screening function¶

One radiograph goes in. It is converted to greyscale, resized to 128 by 128 pixels and scaled, exactly as during training. Both models score it, and the CNN's Grad-CAM map shows which regions drove its decision (Selvaraju et al., 2017). Each model is judged against its own threshold, because the two models' scores are not on the same scale.

def gradCamHeatmap(modelInput, cutOff=0.5):
    camModel = keras.Model(pneumoniaNet.input,
                           [pneumoniaNet.get_layer("lastConv").output, pneumoniaNet.output])
    with tflib.GradientTape() as gradientTape:
        featureMaps, pneumoniaScore = camModel(modelInput[None, ...], training=False)
        targetScore = pneumoniaScore[:, 0] if float(pneumoniaScore[0, 0]) >= cutOff else 1 - pneumoniaScore[:, 0]
    channelWeights = tflib.reduce_mean(gradientTape.gradient(targetScore, featureMaps), axis=(1, 2))
    coarseMap = tflib.nn.relu(tflib.reduce_sum(featureMaps[0] * channelWeights[0], axis=-1)).numpy()
    if coarseMap.max() > 0:
        coarseMap = coarseMap / coarseMap.max()
    return cv2.resize(coarseMap, (imageSide, imageSide), interpolation=cv2.INTER_LINEAR)


def screenRadiograph(imagePath, svmCut=0.5, cnnCut=0.5):
    rawImage = cv2.imread(imagePath, cv2.IMREAD_GRAYSCALE)
    resizedImage = cv2.resize(rawImage, (imageSide, imageSide), interpolation=cv2.INTER_AREA)
    modelInput = (resizedImage.astype("float32") / 255.0)[..., None]
    svmScore = float(hogSvm.predict_proba(hog(modelInput[..., 0], **hogSettings)[None, :])[0, 1])
    cnnScore = float(pneumoniaNet.predict(modelInput[None, ...], verbose=0)[0, 0])

    figureHandle, axisArray = pltlib.subplots(1, 2, figsize=(8, 4))
    axisArray[0].imshow(resizedImage, cmap="gray")
    axisArray[0].set_title(os.path.basename(imagePath), fontsize=9)
    axisArray[1].imshow(resizedImage, cmap="gray")
    axisArray[1].imshow(gradCamHeatmap(modelInput, cnnCut), cmap="jet", alpha=0.4)
    axisArray[1].set_title(f"CNN Grad-CAM, evidence for "
                           f"{'pneumonia' if cnnScore >= cnnCut else 'normal'}", fontsize=9)
    for axisHandle in axisArray:
        axisHandle.axis("off")
    pltlib.tight_layout()
    pltlib.show()

    trueFolder = os.path.basename(os.path.dirname(imagePath))
    print(f"true label (from folder): {trueFolder.lower()}")
    print(sectionRule)
    for modelName, modelScore, cutOff in (("HOG + SVM", svmScore, svmCut), ("CNN", cnnScore, cnnCut)):
        verdict = "PNEUMONIA - prioritise for review" if modelScore >= cutOff else "no pneumonia flagged"
        print(f"{modelName:<10} p(pneumonia) = {modelScore:.3f}  (threshold {cutOff:.3f})  ->  {verdict}")

Demonstration¶

Four test radiographs that neither model was trained on: a normal case, a bacterial pneumonia, a viral pneumonia and a bacterial pneumonia on which the two models disagree. The images are unseen, but the person numbers of the three pneumonia cases are among the 170 that also appear in the training folder, there under a different subtype, so patient independence cannot be confirmed (see the main notebook).
