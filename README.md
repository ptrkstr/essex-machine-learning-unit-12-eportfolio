# essex-machine-learning-unit-12-eportfolio

Source for the individual e-portfolio site for the Machine Learning module
(PCOM7E), University of Essex Online.

The site is a Jekyll site rendered by GitHub Pages. Content is written in
Markdown; no hand-written HTML is required. Pages builds the Markdown into a
styled site using the configured theme. Executed notebooks are included as
static HTML under `artefacts/`.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open the local address that Jekyll prints.

This repository is kept as a single commit; changes are amended onto that commit
rather than added as new commits.
